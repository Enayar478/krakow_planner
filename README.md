# Krakow Planner

Application de planification pour un voyage à Cracovie. Inclut :
- Planning journalier
- Spots secrets
- Lieux romantiques
- Recommandations d'hôtels
- Conseils pratiques

Pour une application de voyage authentique, je proposerais une direction artistique qui combine modernité et authenticité. Voici ma proposition détaillée :
**Thème Principal** : "Local Explorer" L'idée est de créer une ambiance qui mélange le côté aventurier moderne avec l'authenticité locale.
**Palette de Couleurs** :
* Couleur Principale : #2A9D8F (Vert-bleu profond) - Représente l'exploration et la confiance
* Couleur Secondaire : #E9C46A (Jaune safran) - Évoque le soleil et l'aventure
* Accents :
   * #F4A261 (Orange terracotta) - Pour les points d'intérêt et les actions
   * #264653 (Bleu marine profond) - Pour le texte principal et les titres
   * #E76F51 (Corail) - Pour les alertes et les éléments importants
**Typographie** :
* Titres : "Karla" - Une police sans-serif moderne mais chaleureuse
* Corps de texte : "Inter" - Excellente lisibilité sur tous les écrans
* Accents : "DM Serif Display" - Pour les noms de lieux spéciaux et citations
**Style Général** :
* Design Épuré mais Chaleureux
   * Coins légèrement arrondis (border-radius: 12px)
   * Ombres douces pour la profondeur
   * Beaucoup d'espace blanc pour la lisibilité
* Éléments Distinctifs :
   * Icônes linéaires avec un trait fin et élégant
   * Petites illustrations dessinées à la main pour les points d'intérêt
   * Utilisation de textures subtiles rappelant le papier pour certains fonds
   * Photos en noir et blanc pour les lieux historiques
   * Photos en couleur pour les spots contemporains
* Composants Spéciaux :
   * Cartes interactives avec un style personnalisé rappelant les cartes anciennes
   * Badges pour identifier les types de lieux (Local Favorite, Hidden Gem, Must-See)
   * Timeline verticale pour les itinéraires
   * Système de notation avec des symboles locaux plutôt que des étoiles classiques
**Micro-interactions** :
* Animations douces et organiques
* Transitions fluides entre les pages
* Feedback visuel subtil sur les interactions
Cette DA combine professionnalisme et authenticité, tout en restant moderne et fonctionnelle. Elle permet de distinguer facilement les contenus tout en gardant une cohérence visuelle forte.
